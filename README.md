# December Town

A small, responsive winter town game built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. Progress and saved work are stored in that browser's local storage.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. Open the Pages URL shown on that settings page after deployment finishes.

The site has no build step or package dependencies.
